# App Store review notes (paste into App Review Information → Notes)

FarmConnect is a companion app for Persephone's Basket vineyard sensors. Access
is gated: a user signs in, then their account must belong to a farm. We have set
up a demo account that is already linked to a farm with sensor history, so you
can review the app immediately without an access code.

  Password: GrapeReview2026

WHAT YOU'LL SEE AFTER SIGNING IN
  • Sensors tab: a farm with 10 provisioned sensor nodes and historical readings.
    Online/offline status can vary because these are physical field devices.
  • If no vineyard map has been saved yet, Sensors first shows the node list.
    Tap "Set up vineyard" to search for a location and place the nodes on a map.
  • On a saved map, tap a block to see its environmental readings and condition
    details. The green/orange/red map colors mean Good, Watch, and Needs attention.
  • Open the ellipsis menu in Sensors and choose "Disease risk" for the separate,
    model-based disease estimates and the "Set bloom date" option.
  • Notes shows daily per-node low/average/high sensor summaries. Chat provides
    an authenticated vineyard assistant that can use the user's farm context.

NOTES
  • Location permission is optional; the app works without it (used only to set
    a vineyard's position for local weather).
  • The disease-risk feature is decision-support with non-removable disclaimers;
    it never recommends a specific pesticide.
  • No third-party ads or analytics SDKs are included.
