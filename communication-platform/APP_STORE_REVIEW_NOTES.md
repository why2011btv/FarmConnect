# App Store review notes (paste into App Review Information → Notes)

FarmConnect is a companion app for Persephone's Basket vineyard sensors. Access
is gated: a user signs in, then their account must belong to a farm. We have set
up a demo account that is already linked to a farm with live sensors, so you can
review the full app immediately.

DEMO ACCOUNT (already has data — no code needed)
  Email:    appreview@persephonesbasket.com
  Password: GrapeReview2026

WHAT YOU'LL SEE AFTER SIGNING IN
  • Sensors tab: "Running Brook Vineyard" with two reporting sensor nodes and
    their latest temperature/humidity readings.
  • Tap a sensor node to see its readings and per-block disease-risk insights.
  • Toolbar leaf icon (top of the Sensors screen): vineyard-wide disease-risk
    estimates with a "Set bloom date" option.

OPTIONAL — testing the access-code flow
  New customers join a farm by entering a one-time access code. To see this:
  sign out, create a new account, and when prompted for an access code enter:
      PB-BGZ4-NKNM-FCT2-YSH6
  This links the new account to the same demo vineyard.

NOTES
  • Location permission is optional; the app works without it (used only to set
    a vineyard's position for local weather).
  • The disease-risk feature is decision-support with non-removable disclaimers;
    it never recommends a specific pesticide.
  • No third-party ads or analytics SDKs are included.
